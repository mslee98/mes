### 데이터 정합성 체크 부분(체크박스)
- 발주 수량보다 납품 계획 수량이 많아지는 경우
- 납품 계획 수량보다 Unit이 많이 생성되는 경우
- FAIL Unit이 납품되는 경우
- 이미 납품된 Unit을 다시 납품하는 경우
- 이미 납품된 Unit의 핵심 S/N이 임의 변경되는 경우
- 삭제된 검출기/렌즈/제품이 기존 Unit 이력에 영향을 주는 경우

### RMA 프로세스 예시
```
고객 클레임 접수
 → 제품 S/N 조회
 → 기존 납품/발주/고객 정보 자동 조회
 → RMA 접수
 → 입고 여부 기록
 → 원인 분석
 → 조치 유형 선택
     - 수리
     - 교체
     - 재작업
     - 반품
     - 폐기
     - 이상 없음
 → 재검사/공정 이력 기록
 → 고객 재납품 또는 종결
 ```
